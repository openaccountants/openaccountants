# Guide attribution and evidence

OpenAccountants publishes tax Guides with sources, methods and applicable periods. It was founded by [Michael Cutajar](https://www.openaccountants.com/network/ecd6fe97-c3ed-4337-8e12-d1e7456201a9). Founder credit identifies that role; it does not imply authorship, review or professional expertise in every jurisdiction.

## Read the evidence

Before applying a Guide, check its jurisdiction, tax year, scope, assumptions, calculation method and official sources. Confirm time-sensitive rates and thresholds against the authority for the applicable period. A publication date or automated source check does not establish that every statement is current.

A named author receives credit for their actual work. `authored_by` and `author_profile` describe authorship. `publisher`, `founder_credit` and `founder_profile` identify OpenAccountants and its founder. Never infer authorship from a reviewer name or an old tier.

## Public metadata

New exports use publisher and optional author fields, not review or attestation states. The generated index uses schema version 2. Current MCP responses, generated packages and LLM inventories omit historical endorsement metadata and remove explicit Guide review labels from served markdown.

Older source files, Git history, downloaded releases and installed packages may still contain `tier`, `reviewed_by`, `verified_by` or `review_status`. The validator accepts valid historical metadata for compatibility; it is not a current professional endorsement. This change does not rewrite historical releases or source files. Regenerate the index/packages and update the self-hosted MCP to apply the current serving policy.

Guides are general reference material. Have a qualified professional in the relevant jurisdiction review outputs before filing or acting on them.
