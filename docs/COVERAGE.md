# Coverage: which number to quote, and where it is measured

**This file says where each coverage figure comes from.** Two sources exist, and they disagree because they count different things. Quote from the right one, and quote a rounded floor anywhere a figure is not restamped by a script.

| Source | What it counts | Where the live figure is published | Figures on 26 September 2026 |
|---|---|---|---|
| Platform (the openaccountants.com database) | Guides published on the website and served by the hosted MCP server | The README stats block between `<!-- oa-stats:start -->` and `<!-- oa-stats:end -->`, restamped by the nightly sync | 1,866 Guides, 229 jurisdictions, 53 accountant-reviewed, 45 named accountants |
| Repository (`skills/` plus `packages/us-federal/`) | Guide files with frontmatter in this repo | The `counts` block of `index.json`, regenerated by the sync, and the counts sentence in `llms.txt`, restamped by `scripts/build-index.py` on every default build | 2,019 Guides, 245 jurisdictions, 168 with `tier: 1` and a named reviewer |

The repository is larger than the platform because it also holds Guides that are not yet published, and its jurisdiction count includes every US state and Canadian province directory. "Accountant-reviewed" differs too: the platform counts Guides whose current text carries a Partner's review, the repository counts frontmatter (`tier: 1` plus a reviewer name).

Rules:

- Do not say "every country". About 195 sovereign states exist; the repository carries 185 country codes.
- Do not collapse the tiers. Most Guides are source-cited drafts; each file states its tier in frontmatter (see [QUALITY-TIERS.md](QUALITY-TIERS.md)), and the website shows the Partner's name on reviewed ones.
- Do not copy an exact figure into a document by hand. It is stale within a day; use the rounded claim or point at the live source.

## How to update

- Platform figures: nothing to do. The nightly sync restamps the README block.
- Repository figures: `python3 scripts/build-index.py` (default mode) rewrites `index.json` and restamps the `llms.txt` sentence; the sync runs it nightly. In a pull request, do not commit `index.json`; it is generated.
- Rounded claims: change them only when a measured figure crosses a floor, then update the table above and every surface it lists in one pull request.
- The dated figures in this file: refresh them whenever you edit it. The live sources above are always current.
