# Accountants on the record

The current roster is the generated [VERIFIERS.md](../VERIFIERS.md) at the repo root, rebuilt nightly from openaccountants.com; the names there appear in `reviewed_by:` on the skills they checked.

Every skill is in one of three attribution states: built by Michael Cutajar and the OpenAccountants team, Accountant-authored (a named accountant approved on openaccountants.com wrote it, not yet independently checked), or Checked by a named accountant other than the author. See [QUALITY-TIERS.md](QUALITY-TIERS.md).
