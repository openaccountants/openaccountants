# Slovakia 2026: ledger and review evidence

The seven sibling `ledgers/<slug>.md` files identify every reviewed figure, rule,
example and disclosed limit. `source-quotes.md` supplies original-language
quotations, official links and provision references. `source-scopes.json` records
the exact raw/reader identities and the portions actually read on the recorded
dates. Downloading a body is not a claim to have read all of it.

## Portable source and historical paths

Historical records retain their exact bytes, including original absolute paths.
`published-artifact-map.json` maps each original path and SHA256 to a file in this
repository. Use that map to locate an artifact in a fresh clone. Retained files
are stored once by their hash when no existing canonical file has the same bytes.
`old-git-bodies/identities.json` records twelve exact Git preimages used by the
old-topic checks. These snapshots live outside the indexed Guide tree.

`original-writer/` preserves the first writer seal and scope. Its superseded
artifacts remain available through the path-and-hash map; they are not silently
replaced by repaired versions. `independent-review/` preserves all 173 sealed
review artifacts, findings, reading bridges, source failures and closure checks.
Prior reviews retain their own dates and scope. The fresh A1 result is an official
administrative-page web-tool observation, not raw HTML or a newly obtained text
of Regulation 883.

Root's merge evidence and technical checks are separate from the independent
review. Source quotations and historical evidence are excluded from the
repository marketing-copy guard; live repository prose remains checked.
