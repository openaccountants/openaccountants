## Option A: qualify the existing route (recommended)

Replace LF34:

- **Employees** (§5). The employer withholds monthly advances. An employee with only §5 income from Slovak employers can ask an employer for the annual settlement (ročné zúčtovanie) by 15 February 2027 if they are not required to increase the tax base under §11(11) for earlier DDS deductions (§38(1)). Otherwise they file DPFO type A.

Replace LF125:

| Ask the employer for the annual settlement (employment income only; no §11(11) DDS addback required) | 15 February 2027 | §38(1) |

This states the statutory exception directly in both places. The existing type A route remains supported by the actual 2026 type A instructions, LF18–37.

## Option B: retain the paragraph and add an explicit exception

Replace LF34:

- **Employees** (§5). The employer withholds monthly advances. An employee with only §5 income from Slovak employers can ask an employer for the annual settlement (ročné zúčtovanie) by 15 February 2027 instead of filing (§38(1)). Otherwise they file DPFO type A. An employee required to add back earlier DDS deductions under §11(11) must file a return instead of requesting this settlement (§32(2)(d), §38(1)).

Replace LF125:

| Ask the employer for the annual settlement (employment income only; the §11(11) exception applies) | 15 February 2027 | §38(1) |

This preserves more of the old sentence but separates its qualification, making the table less self-contained.

## Source and separating control

ITA §38(1): “a ktorý nie je povinný zvýšiť základ dane podľa § 11 ods. 11”. The current type A instructions expressly include a taxpayer who “je povinný zvýšiť základ dane podľa § 11 ods. 11”. Read 2026-10-29; official URLs are recorded in the source ledger.

Same employee, only §5 income and otherwise eligible: no §11(11) increase required → annual-settlement request available; increase required → this request route is unavailable and the return duty applies. The change adds no new amount, deadline or income category. Existing statutory DDS timing in LF93 remains unchanged.
