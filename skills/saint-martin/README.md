# Saint-Martin (French): tax pack

French Saint-Martin (MF) is a French overseas collectivity with its own tax code (Code general des impots de la collectivite de Saint-Martin), separate from Dutch Sint Maarten (SX). There is no VAT: the collectivity levies the TGCA (4%). Taxes are administered by the Centre des finances publiques de Saint-Martin for the Collectivite. Amounts in euros. From 1 January 2026, professional returns go by email as PDF and payments by bank transfer.
