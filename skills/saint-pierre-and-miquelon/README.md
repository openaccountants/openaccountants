# Saint-Pierre-et-Miquelon: tax pack

Saint-Pierre-et-Miquelon (PM) is a French overseas collectivity with its own tax code (Code local des impots), administered by the Direction des services fiscaux (services-fiscaux975.fr). Mainland French rates do not apply. Amounts in euros.
