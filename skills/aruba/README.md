# Aruba: tax pack

Tax year: the calendar year (2026). Authority: Departamento di Impuesto (DIMP), which also collects the AOV/AWW and AZV premiums; the SVB runs AOV, AWW, ZV and OV. Aruba has no VAT: it levies the turnover taxes BBO, BAVP and BAZV (7% together), also at the border on imports. Amounts are Aruban florins (Afl.).
