# Saint-Barthelemy: tax pack

Saint-Barthelemy (BL) is a French overseas collectivity with its own tax powers and its own Code des contributions. Amounts are in euros. This pack covers two local levies so far; the tax domains below are not yet written, and whether each applies locally has not been checked.
