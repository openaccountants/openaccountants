# Countries

223 country packs. Open a country to see which skill covers which tax, and what is still missing.
"On 2026" counts skills on the current tax year. State is the next job a pack needs: Needs writing (a required tax area is missing), Needs updating (a required skill is on an old or missing tax year), Ready for an accountant (current, waiting for an accountant's approval), Complete. This page is generated by `scripts/build-country-index.py`.
