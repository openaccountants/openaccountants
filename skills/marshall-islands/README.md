# Marshall Islands (MH): tax pack

**Built from the law. Not yet approved. Written by Ryan Duguid. Not reviewed by an accountant.** The Republic of the Marshall Islands uses the US dollar. Laws are published by the Nitijela (rmiparliament.org). Social security is run by the Marshall Islands Social Security Administration (MISSA), which collects the Retirement Fund contribution quarterly; the Health Fund is a separate programme. Tax year 2026.
