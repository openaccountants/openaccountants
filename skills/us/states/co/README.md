# Colorado: 2026 tax skills

Colorado has individual and corporate income tax, sales/use tax, employer wage
withholding, UI and FAMLI. Federal and state layers are separate. Self-collecting
home-rule sales-tax systems require their own analysis; Colorado's retail delivery
fee is a separate state fee/account, with a midyear rate change. The pack does
not establish a separate general franchise/gross-receipts tax obligation.

## Boundaries

Property taxes, estate/inheritance questions, severance, marijuana/special excises,
lodging, vehicle registration, construction permits and enterprise-zone credits
are outside these core calculations. Related-party/group, international and
special-industry rules need their current source analysis. Labor-law subjects
already present in the payroll file remain named as pending, not silently verified.
