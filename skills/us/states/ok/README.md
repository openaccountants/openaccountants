# Oklahoma: 2026 tax skills

Oklahoma taxes individual wages, ordinary corporate income, sales/use and employer payroll. The franchise return ended after tax year 2023; it is not an omitted 2026 job. Separate industry gross-production, property, tribal and entity-registration matters are outside these four ordinary tax jobs. Every changed skill remains a source-cited draft pending independent review.
