# Solomon Islands (SB): tax pack

**Built from the law. Not yet approved. Written by Ryan Duguid. Not reviewed by an accountant.** The Solomon Islands uses the Solomon Islands dollar (SBD). Laws are published by the Attorney-General's Chambers (attorneygenerals.gov.sb). Retirement savings run through the Solomon Islands National Provident Fund (SINPF). Tax year 2026.
